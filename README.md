# Генератор рекламных роликов — версия для Railway

Вставляете ссылку на сайт → нейросеть пишет рекламный сценарий, рисует сцены (GPT Image 2, FLUX), озвучивает живым голосом (ElevenLabs) и собирает MP4 для TikTok, Instagram Reels и YouTube Shorts.

## Что делает сервер

- **Хранит ключ fal.ai** в переменных Railway. Пользователи его не видят и не вводят.
- **Закрывает сайт паролем**, чтобы никто чужой не тратил ваш баланс.
- **Пропускает к fal.ai только нужные модели** (сценарий, картинки, оживление, голос, музыка) — остальные запросы отклоняются.
- **Сам читает сайты** и находит текст, цену и фото товара (включая разметку магазинов JSON-LD) — надёжнее, чем через сторонние сервисы.

Видео монтируется в браузере пользователя, поэтому сервер лёгкий и дешёвый: хватит минимального тарифа Railway.

## Деплой на Railway (5 минут)

1. **Залейте папку в GitHub.** Создайте новый репозиторий на github.com и загрузите в него все файлы из архива (кнопка «Add file → Upload files»). Папку `node_modules` загружать не нужно.
2. **Создайте проект в Railway.** На [railway.com](https://railway.com) → New Project → Deploy from GitHub repo → выберите репозиторий. Railway сам поймёт, что это Node.js, и запустит `npm start`.
3. **Добавьте переменные.** Откройте сервис → вкладка **Variables** → добавьте:
   - `FAL_KEY` — ваш ключ с [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys)
   - `APP_PASSWORD` — пароль для входа на сайт (придумайте надёжный)
   - `SESSION_SECRET` — любая длинная случайная строка (необязательно, но лучше задать)
4. **Получите адрес.** Вкладка **Settings → Networking → Generate Domain**. Откройте ссылку, введите пароль — готово.

Railway сам пересоберёт сайт после каждого изменения в репозитории.

### Через Railway CLI (если удобнее из терминала)

```bash
npm i -g @railway/cli
railway login
railway init
railway up
railway variables --set "FAL_KEY=..." --set "APP_PASSWORD=..." --set "SESSION_SECRET=..."
railway domain
```

## Режимы работы

| Переменные | Как работает |
|---|---|
| `FAL_KEY` + `APP_PASSWORD` | Вход по паролю, ключ на сервере. **Рекомендуется.** |
| только `APP_PASSWORD` | Вход по паролю, каждый вводит свой ключ fal. |
| ничего | Открытый сайт, каждый вводит свой ключ fal. |
| только `FAL_KEY` | Серверный ключ **отключается** ради безопасности — задайте `APP_PASSWORD`. Если сайт должен быть открытым с вашим ключом, добавьте `ALLOW_PUBLIC=true` (кто угодно сможет тратить ваш баланс). |

## Запуск на своём компьютере

```bash
npm install
FAL_KEY=ваш_ключ APP_PASSWORD=пароль npm start
# откройте http://localhost:3000
```

## Структура

- `server.js` — сервер: вход, прокси к fal.ai, чтение сайтов.
- `public/index.html` — само приложение (интерфейс, сценарий, сцены, озвучка, монтаж видео).
- `railway.json` — настройки запуска и проверки здоровья для Railway.

## Важно

- Готовые видео собираются в браузере: лучше всего в Chrome или Edge на компьютере (MP4 с H.264 для Instagram).
- Проекты сохраняются в браузере пользователя, а не на сервере.
- Расходы fal.ai списываются с баланса ключа `FAL_KEY` — следите за ними в кабинете fal.ai. Там же можно поставить лимит трат.
